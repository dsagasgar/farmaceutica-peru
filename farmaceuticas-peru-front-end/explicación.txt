# FLUJO DE LA APLICACIÓN "FARMACÉUTICAS PERÚ"

## 1. ARRANQUE Y CONFIGURACIÓN
--------------------------
- `main.ts` -> Punto de entrada. Arranca la app usando la configuración de:
- `app.config.ts` -> Registra servicios globales como el enrutador (`provideRouter`) y el cliente HTTP.
- `app.ts` -> Componente raíz que contiene `<router-outlet>`, el espacio donde se cargan las páginas.

## 2. ENRUTAMIENTO Y SEGURIDAD
---------------------------
- `app.routes.ts`
  - Función: Define las URLs de la aplicación (ej. '/login', '/dashboard/cajero').
  - Conexión: Asocia cada URL con un componente y utiliza `auth.guard.ts` para proteger las rutas de los dashboards.
- `guards/auth.guard.ts`
  - Función: Protege las rutas. Antes de permitir el acceso, pregunta al `AuthService` si el usuario ha iniciado sesión y tiene el rol correcto.
  - Conexión: Si no se cumplen las condiciones, redirige al usuario a '/login'.

## 3. MODELOS DE DATOS (El "plano" de la información)
------------------------------------------------
- `models/types.ts`
  - Función: Define la estructura de los objetos clave del sistema (`Usuario`, `Producto`, `Venta`, `CompraProveedor`). Actúa como un contrato para asegurar que los datos sean consistentes en toda la app.

## 4. SERVICIOS (Lógica de negocio centralizada)
---------------------------------------
(Clases reutilizables que manejan datos y lógica, sin interfaz de usuario).

- `services/auth.service.ts`
  - Función: Gestiona la sesión del usuario (login, logout, datos del usuario actual).
  - Conexiones: Usado por `LoginComponent`, `auth.guard.ts` y todos los dashboards.

- `services/producto.service.ts`
  - Función: Gestiona los datos de los productos (obtener, buscar, actualizar stock).
  - Conexiones: Usado por `catalogo-productos.component.ts`, `nuevo-pedido.component.ts` y es llamado por `venta.service.ts` para descontar stock.

- `services/venta.service.ts`
  - Función: Gestiona las órdenes de venta (crear, buscar, registrar pago).
  - Conexiones: Usado por `nuevo-pedido.component.ts` y `cajero-dashboard.component.ts`. Llama a `producto.service.ts`.

- `services/compra.service.ts`
  - Función: Gestiona las órdenes de compra a proveedores.
  - Conexiones: Usado por `almacen-dashboard.component.ts` para listar y procesar las recepciones de mercadería.

## 5. COMPONENTES (La interfaz de usuario)
-----------------------------------------------------
(Piezas visuales con su propio HTML, CSS y lógica).

- `pages/login/login.component.ts`
  - Función: Muestra el formulario de login.
  - Flujo: Llama a `authService.login()` y, si tiene éxito, usa el `Router` para navegar al dashboard correspondiente.

- `pages/dashboards/quimico-dashboard.component.ts`
  - Función: Panel del Químico.
  - Flujo: Contiene los componentes `<app-catalogo-productos>` y `<app-nuevo-pedido>`. Orquesta la creación de una nueva orden de venta.

- `pages/componentes/nuevo-pedido.component.ts`
  - Función: Formulario reutilizable para crear una orden de venta.
  - Flujo: Usa `productoService` para buscar productos y `ventaService` para guardar la nueva orden. Emite un evento `(pedidoGenerado)` para notificar al componente padre (el dashboard) que ha terminado.

- `pages/dashboards/cajero-dashboard.component.ts`
  - Función: Panel del Cajero.
  - Flujo: Usa `ventaService` para buscar una orden por ID y registrar su pago.

- `pages/dashboards/almacen-dashboard.component.ts`
  - Función: Panel del Almacenero.
  - Flujo: Usa `compraService` para obtener y procesar las compras pendientes de recepción.

- `pages/dashboards/admin-dashboard.component.ts`
  - Función: Panel del Administrador.
  - Flujo: Muestra un resumen general y accesos directos a las diferentes áreas de gestión.
